# Reglas de documentación

## Idioma

Priorizar términos en español.

- deployment → despliegue
- folder → carpeta
- branch → rama
- commit → confirmación de cambios (cuando aplique)

Mantener en inglés solo los términos estándar de la industria y los nombres
reales de código (rutas, clases, comandos, endpoints).

## Modo estricto

Toda salida debe:

- Estar en español, salvo identificadores de código.
- Usar UTF-8, tildes correctas y la letra ñ cuando corresponda.
- Tener calidad suficiente para publicarse sin retoques.
